# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. This website showcases your skills, projects, and professional information in an elegant and professional manner.

## Features

- 🎨 Modern and responsive design
- 📱 Mobile-friendly layout
- ⚡ Fast loading and lightweight
- 🚀 Deployed on GitHub Pages
- 💫 Smooth animations and transitions
- 📧 Contact information section
- 🛠️ Skills and technologies showcase
- 💼 Project portfolio display

## Sections

- **Hero**: Eye-catching introduction with call-to-action
- **About**: Personal introduction and background
- **Skills**: Technical skills and technologies
- **Projects**: Featured work and projects
- **Contact**: Contact information and social links

## Customization

To customize this portfolio for your own use:

1. Replace "Your Name" with your actual name
2. Update the email, LinkedIn, and GitHub links in the contact section
3. Modify the about section with your personal information
4. Update the skills section with your technical expertise
5. Replace the project examples with your actual projects
6. Add your profile image or update the emoji placeholder

## Deployment

This website is automatically deployed to GitHub Pages when changes are pushed to the main branch. The live website will be available at:

`https://yourusername.github.io/trending/`

## Local Development

To run the website locally:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js (if you have it installed)
npx serve .
```

Then open `http://localhost:8000` in your browser.

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- Vanilla JavaScript
- GitHub Pages for hosting
